# 図の選定カタログ

先に「誰が何を理解・判断するか」を決める。以下は36の用途候補であり、36種類の描画エンジンが実装済みという意味ではない。同じ状態遷移図でも、初心者向けには具体例、QA向けには条件と例外を強調する。

## 現在使えるビュー

Design / Concept / ER に加え、U04（状態遷移）、U06（サービスブループリント）、E02（シーケンス）、E11（リネージュ）、M01（KPI分解）を実装している。その他は追加候補。未対応のデータ項目を既存ビューに押し込み、図が表している意味を変えない。

| 読み手 | まず見せる情報 | 詳細として残す情報 |
|---|---|---|
| 初心者 | 具体的な対象、平易な動詞、現在の範囲 | 専門語の意味、次へ進む条件、例外 |
| エンジニア | 境界、順序、キー、責務、制約 | 実装識別子、根拠、失敗・再送・検証条件 |
| 経営・事業責任者 | 判断したい成果と構成要素、比較条件 | 定義、単位、期間、費用範囲、不確実性 |

図の型を増やす際は、問い・必要な根拠・接続する既存ID・矢印の意味・未対応条件を先に定義する。数量比較はチャート、正確な対応は表、分岐と依存は図を使う。判断に不可欠な条件を、図を小さくする目的で削らない。

## 候補一覧

参照欄は手法の着眼点を得た資料。CRMへの適用や実装優先度はこのスキルの設計判断。R0〜R3は本スキルのREADME・選定方針・モデルスキーマ・実行可能なサンプルを指す。
